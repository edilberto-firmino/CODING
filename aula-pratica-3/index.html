00 · Prepare a nova versão

01 · Reconheça os tipos de erro

TipoExemploComo investigar
Sintaxeif media >= 7, sem dois-pontosCorrija a estrutura indicada antes de executar.

Nem todo erro encerra o programa: uma regra incorreta pode produzir uma saída aparentemente normal. Para encontrar esse tipo de falha, precisamos de resultados esperados.

Leia o traceback

def converter_nota(texto):
    return float(texto)

converter_nota("sete")

Execute esse exemplo sozinho. O trecho final da mensagem será semelhante a:

  File "experimentos.py", line 2, in converter_nota
    return float(texto)
ValueError: could not convert string to float: 'sete'

O caminho e as linhas variam conforme seu arquivo. Comece pela última linha, que mostra o tipo e a mensagem. Depois observe a linha do seu código onde a falha aconteceu e as chamadas anteriores. Não confunda a linha onde o erro apareceu com sua causa: o texto inválido veio de quem chamou a função.

Sua vez · classifique e explique

  1. Execute, separadamente: 10 / 0, [8, 9][2] e {"nome": "Ana"}["notas"].
  2. Registre o tipo de exceção, a operação que falhou e uma forma de evitar o problema.
  3. Calcule 8 + 6 / 2 e compare com a média esperada, 7. Explique por que não houve uma exceção.
  4. Em um arquivo separado, remova os dois-pontos de um if. Observe o SyntaxError, corrija e execute novamente.

02 · Trate falhas esperadas

Um bloco try delimita uma operação que pode falhar. Um except específico define como responder àquela exceção. O restante do bloco try é interrompido quando a exceção ocorre.

try:
    nota = float(input("Nota: "))
except ValueError:
    print("Você precisa digitar um número.")
else:
    print(f"Número recebido: {nota:.2f}")

else executa quando o bloco try termina sem exceção. Aqui, receber 12 não causa ValueError: é um número válido para conversão, mas está fora da regra das notas. Trataremos isso na próxima etapa.

Mais de uma falha possível

try:
    total = float(input("Total: "))
    pessoas = int(input("Quantidade de pessoas: "))
    valor = total / pessoas
except ValueError:
    print("Digite números nos formatos solicitados.")
except ZeroDivisionError:
    print("Não é possível dividir por zero pessoas.")
else:
    print(f"Valor por pessoa: R$ {valor:.2f}")
Capture a exceção que você sabe tratar. Evite except: e except Exception: pass: eles podem esconder defeitos e fazer o programa continuar com dados incompletos. Mantenha o try próximo da operação que pode falhar.

Onde entra finally?

finally executa ao sair do bloco, mesmo quando há exceção. É usado para finalização de recursos; não é necessário para validar uma nota. Como observação de fluxo, experimente acrescentar finally: print("Tentativa concluída.") ao primeiro exemplo e compare uma entrada válida com uma inválida.

Sua vez · divisão controlada

  1. Execute o exemplo com 100 e 4, depois com cem, depois com 100 e 0.
  2. Acrescente uma regra para recusar total negativo e quantidade de pessoas menor ou igual a zero antes de dividir.
  3. Registre a diferença entre conversão inválida e valor numérico que viola uma regra.

03 · Valide e peça novamente

Validar envolve três perguntas: o texto pode ser convertido? O valor respeita a regra? Se não respeitar, como o usuário pode tentar novamente?

def ler_nota(mensagem):
    while True:
        entrada = input(mensagem).strip().replace(",", ".")
        try:
            nota = float(entrada)
        except ValueError:
            print("Digite uma nota numérica.")
            continue
        if not 0 <= nota <= 10:
            print("A nota deve estar entre 0 e 10.")
            continue
        return nota

nota = ler_nota("Nota: ")
print(f"Nota aceita: {nota:.2f}")

continue inicia a próxima tentativa. return encerra a função somente quando a nota é aceita. strip() remove espaços das extremidades; replace() permite usar vírgula como separador decimal. Esse tratamento não é um leitor de valores monetários com separadores de milhar.

Texto vazio também precisa de regra

def ler_texto(mensagem):
    while True:
        texto = input(mensagem).strip()
        if texto:
            return texto
        print("O texto não pode ficar vazio.")

Use raise nas regras do sistema

A função que lá o teclado pode pedir novamente. Uma função de cadastro, que também pode ser chamada por outro código, deve sinalizar a regra violada. raise permite gerar uma exceção de propósito.

def validar_matricula(matricula):
    if not matricula.strip():
        raise ValueError("A matrícula é obrigatória.")
    return matricula.strip()

try:
    matricula = validar_matricula("   ")
except ValueError as erro:
    print(f"Cadastro recusado: {erro}")

Sua vez · entradas confiáveis

  1. Teste ler_nota() digitando nesta ordem: sete, -1, 11 e 7,5. Somente o último valor deve ser aceito.
  2. Teste os limites 0 e 10. Ambos são válidos.
  3. Teste ler_texto() com Enter, espaços e depois um nome.
  4. Crie ler_opcao() para aceitar somente as strings "0", "1", "2", "3" e "4". Uma opção inválida deve solicitar nova tentativa.
Aprofundamento · números especiais

float() também aceita nan e inf. Não representam notas válidas. A condição not 0 <= nota <= 10 já os recusa. Na referência, usamos também math.isfinite(nota) para deixar explícito que esperamos um número finito. Teste essas entradas e observe a recusa.

04 · Investigue antes de corrigir

Use esta sequência: reproduza a falha → anote esperado e obtido → localize a etapa divergente → formule uma hipótese → faça uma mudança pequena → execute novamente → confira os casos anteriores.

def calcular_media(notas):
    total = sum(notas)
    quantidade = len(notas)
    return total / quantidade - 1

print(calcular_media([8, 6]))  # Esperado: 7.0; obtido: 6.0

Laboratório · três defeitos

  1. Execute o exemplo e inspecione total e quantidade com prints temporários, ou com um breakpoint no editor. Identifique a operação incorreta e corrija.
  2. Execute com []. Defina o contrato: sem notas, o resultado deve ser None. Corrija sem capturar indiscriminadamente todos os erros.
  3. Crie uma classificação que usa media > 7. Teste a média exata 7 e ajuste para aprovação a partir de 7.
  4. Registre cada investigação em respostas.md: entrada, esperado, obtido, hipótese, correção e resultado após a mudança.
  5. Remova os prints temporários e execute novamente todos os casos.
Zero não significa ausência de notas. A média 0.0 é válida. Use media is None para reconhecer ausência; if not media confundiria as duas situações.

Sem notas não significa reprovado

Adapte definir_situacao(media) para devolver “Sem notas” quando recebe None. Na apresentação, só use :.2f quando houver uma média numérica.

05 · Proteja as correções

Um teste compara um comportamento com um resultado esperado. Um teste de regressão guarda um caso que falhou para perceber se o problema reaparecer.

from turma import calcular_media, definir_situacao

assert calcular_media([8, 6]) == 7
assert calcular_media([0, 0]) == 0
assert calcular_media([]) is None
assert definir_situacao(4) == "Recuperação"
assert definir_situacao(7) == "Aprovado"
assert definir_situacao(None) == "Sem notas"
print("Conferências concluídas.")

Salve em conferir.py depois de implementar as funções em turma.py. Execute python conferir.py. Uma condição falsa produz AssertionError; sem falhas, você verá a mensagem final. Não execute com -O, pois essa opção desativa asserts.

Use assert para conferir o desenvolvimento. Para validar dados da aplicação, use condições e exceções: asserts podem ser desativados.

Passo 1 · Defina os contratos

  • calcular_media(notas): retorna média, ou None para lista vazia. Notas precisam ser números finitos de 0 a 10; dados inválidos geram ValueError.
  • definir_situacao(media): recebe média válida ou None; retorna Aprovado, Recuperação, Reprovado ou Sem notas.
  • buscar_aluno(alunos, matricula): retorna o registro ou None.
  • cadastrar_aluno(alunos, matricula, nome, notas): recebe matrícula e nome como strings, remove espaços nas extremidades, recusa campos vazios ou matrícula repetida e valida notas. Só adiciona o registro depois de todas as verificações. Retorna o aluno cadastrado; nas recusas, gera ValueError.
  • resumir_turma(alunos): retorna um dicionário com total, com_notas e media_geral. Conte todos os alunos no total, mas calcule a média geral apenas com aqueles que têm notas. Se ninguém tiver notas, a média geral será None.

Estrutura de cada registro: {"matricula": "001", "nome": "Ana", "notas": [8.0, 9.0]}. Uma lista vazia de notas também é aceita pelas regras para representar aluno ainda não avaliado.

"""Entrada de dados no terminal, com novas tentativas quando necessário."""

import math


def ler_texto(mensagem):
    """Solicita texto até receber pelo menos um caractere não branco."""
    while True:
        texto = input(mensagem).strip()
        if texto:
            return texto
        print("O texto não pode ficar vazio.")


def ler_nota(mensagem):
    """Solicita uma nota finita entre zero e dez; aceita vírgula decimal."""
    while True:
        entrada = input(mensagem).strip().replace(",", ".")
        try:
            nota = float(entrada)
        except ValueError:
            print("Digite um número, por exemplo 7.5 ou 7,5.")
            continue
        if not math.isfinite(nota) or not 0 <= nota <= 10:
            print("A nota deve estar entre 0 e 10.")
            continue
        return nota


def ler_opcao():
    """Solicita uma das opções disponíveis no menu."""
    while True:
        opcao = input("Escolha: ").strip()
        if opcao in ("0", "1", "2", "3", "4"):
            return opcao
        print("Opção inválida. Escolha 0, 1, 2, 3 ou 4.")

Baixar turma.py

"""Regras da turma, independentes do teclado e da apresentação."""

import math


def calcular_media(notas):
    """Devolve a média ou None quando não há notas.

    Notas devem ser números finitos entre 0 e 10; caso contrário,
    a função sinaliza ValueError. A coleção recebida não é alterada.
    """
    if not notas:
        return None
    for nota in notas:
        if isinstance(nota, bool) or not isinstance(nota, (int, float)):
            raise ValueError("Cada nota deve ser um número entre 0 e 10.")
        if not math.isfinite(nota) or not 0 <= nota <= 10:
            raise ValueError("Cada nota deve ser um número entre 0 e 10.")
    return sum(notas) / len(notas)


def definir_situacao(media):
    """Recebe média válida ou None e devolve a situação acadêmica."""
    if media is None:
        return "Sem notas"
    if media >= 7:
        return "Aprovado"
    if media >= 4:
        return "Recuperação"
    return "Reprovado"


def buscar_aluno(alunos, matricula):
    """Devolve o registro encontrado, ou None quando ausente."""
    for aluno in alunos:
        if aluno["matricula"] == matricula:
            return aluno
    return None


def cadastrar_aluno(alunos, matricula, nome, notas):
    """Adiciona um novo registro válido ou sinaliza ValueError.

    Matrícula e nome devem ser strings. Matrícula é única após strip().
    A lista de notas é copiada antes de ser armazenada.
    """
    matricula = matricula.strip()
    nome = nome.strip()
    if not matricula or not nome:
        raise ValueError("Matrícula e nome são obrigatórios.")
    if buscar_aluno(alunos, matricula) is not None:
        raise ValueError("Matrícula já cadastrada.")
    calcular_media(notas)
    aluno = {"matricula": matricula, "nome": nome, "notas": list(notas)}
    alunos.append(aluno)
    return aluno


def resumir_turma(alunos):
    """Conta todos os alunos e calcula a média apenas dos que têm notas."""
    medias = []
    for aluno in alunos:
        media = calcular_media(aluno["notas"])
        if media is not None:
            medias.append(media)
    return {
        "total": len(alunos),
        "com_notas": len(medias),
        "media_geral": calcular_media(medias),
    }

main.py

Baixar main.py

"""Menu interativo do sistema acadêmico da prática 3."""

from turma import (
    buscar_aluno, cadastrar_aluno, calcular_media,
    definir_situacao, resumir_turma,
)
from validacoes import ler_nota, ler_opcao, ler_texto


def exibir_aluno(aluno):
    """Apresenta um registro, inclusive quando ainda não possui notas."""
    media = calcular_media(aluno["notas"])
    media_exibida = "Sem notas" if media is None else f"{media:.2f}"
    print(f"{aluno['matricula']} | {aluno['nome']} | "
          f"{media_exibida} | {definir_situacao(media)}")


def main():
    """Executa o menu até a escolha de sair; dados ficam na memória."""
    alunos = []
    while True:
        print("\n=== SISTEMA ACADÊMICO ===")
        print("1 - Cadastrar aluno")
        print("2 - Listar alunos")
        print("3 - Buscar matrícula")
        print("4 - Resumir turma")
        print("0 - Sair")
        opcao = ler_opcao()

        if opcao == "0":
            print("Programa encerrado.")
            break
        if opcao == "1":
            matricula = ler_texto("Matrícula: ")
            if buscar_aluno(alunos, matricula) is not None:
                print("Matrícula já cadastrada.")
                continue
            nome = ler_texto("Nome: ")
            notas = [ler_nota("Nota 1: "), ler_nota("Nota 2: ")]
            try:
                cadastrar_aluno(alunos, matricula, nome, notas)
            except ValueError as erro:
                print(f"Cadastro recusado: {erro}")
            else:
                print("Aluno cadastrado.")
        elif opcao == "2":
            if not alunos:
                print("Nenhum aluno cadastrado.")
            for aluno in alunos:
                exibir_aluno(aluno)
        elif opcao == "3":
            matricula = ler_texto("Matrícula a buscar: ")
            aluno = buscar_aluno(alunos, matricula)
            if aluno is None:
                print("Aluno não encontrado.")
            else:
                exibir_aluno(aluno)
        elif opcao == "4":
            resumo = resumir_turma(alunos)
            print(f"Total: {resumo['total']} | Com notas: {resumo['com_notas']}")
            if resumo["media_geral"] is None:
                print("Média geral: Sem dados")
            else:
                print(f"Média geral: {resumo['media_geral']:.2f}")


if __name__ == "__main__":
    main()

Baixar conferir.py

"""Conferências de regras e limites. Execute com python conferir.py."""

from turma import (
    buscar_aluno, cadastrar_aluno, calcular_media,
    definir_situacao, resumir_turma,
)


def conferir():
    assert calcular_media([8, 6]) == 7
    assert calcular_media([0, 0]) == 0
    assert calcular_media([10, 10]) == 10
    assert calcular_media([]) is None
    assert definir_situacao(None) == "Sem notas"
    for media, esperado in [(3.9, "Reprovado"), (4, "Recuperação"),
                             (6.9, "Recuperação"), (7, "Aprovado")]:
        assert definir_situacao(media) == esperado

    for notas in [[-1], [11], ["sete"], [float("nan")], [float("inf")], [True]]:
        try:
            calcular_media(notas)
        except ValueError:
            pass  # O erro é o resultado esperado neste caso de teste.
        else:
            raise AssertionError(f"Notas inválidas aceitas: {notas}")

    alunos = []
    assert buscar_aluno(alunos, "999") is None
    assert resumir_turma(alunos) == {"total": 0, "com_notas": 0, "media_geral": None}
    notas = [8, 9]
    cadastrar_aluno(alunos, "001", "Ana", notas)
    notas.append(0)
    assert alunos[0]["notas"] == [8, 9]
    cadastrar_aluno(alunos, "002", "Bruno", [6, 7])
    cadastrar_aluno(alunos, "003", "Carla", [])
    assert buscar_aluno(alunos, "002")["nome"] == "Bruno"
    assert resumir_turma(alunos) == {"total": 3, "com_notas": 2, "media_geral": 7.5}
    assert resumir_turma([alunos[2]])["media_geral"] is None

    for matricula, nome, notas in [(" 001 ", "Outra Ana", [7, 7]),
                                    ("", "Eva", [7, 7]),
                                    ("004", "  ", [7, 7]),
                                    ("004", "Eva", [11, 7])]:
        antes = len(alunos)
        try:
            cadastrar_aluno(alunos, matricula, nome, notas)
        except ValueError:
            assert len(alunos) == antes
        else:
            raise AssertionError("Cadastro inválido foi aceito.")
    print("Conferências concluídas.")


if __name__ == "__main__":
    conferir()

A referência inclui conferências de cadastro recusado, turma sem notas, limites de aprovação e preservação da lista após falhas. O pass no teste de exceção indica que a falha era esperada naquele teste; não é uma orientação para esconder falhas no programa.

  • Executei as conferências e o roteiro manual do menu.
  • As regras estão separadas das entradas e da apresentação.

Entregue sua pasta com os seis arquivos indicados no desafio. Em respostas.md, inclua as respostas das atividades, o registro dos três defeitos investigados e uma tabela com entrada, resultado esperado e resultado obtido dos casos que você conferiu.

Como demonstrar domínio

Apresente um cadastro válido, uma entrada inválida que permite nova tentativa e uma conferência automática. Explique onde a falha é detectada, qual função devolve o resultado e por que o programa pode continuar. Código funcionando e explicação coerente devem acompanhar a entrega.

Se terminar antes

Adicione uma opção para cadastrar um aluno sem notas e outra para lançar suas notas depois. Verifique se o resumo passa a considerá-lo somente após receber notas. Crie um teste de regressão para essa mudança.
