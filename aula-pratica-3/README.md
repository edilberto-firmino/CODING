# Aula prática 3 — Erros, validação e depuração

Abra [index.html](index.html) para acompanhar as instruções destinadas aos alunos.

Pré-requisitos: funções, return, coleções e imports da prática 2. Duração sugerida: quatro horas. Os exercícios usam Python 3, sem pacotes externos.

O roteiro inclui leitura de traceback, exceções específicas, repetição de entrada, regras de validação, depuração e testes de regressão. O desafio evolui o sistema acadêmico com um menu no terminal.

A pasta `referencia` contém uma solução para consulta após a tentativa. Para executá-la, abra um terminal nessa pasta e use:

```text
python main.py
python conferir.py
```

Os dados ficam na memória e são descartados ao encerrar o programa. O menu cadastra dois valores de nota por aluno; o caso de aluno sem notas é trabalhado nas funções e nas conferências.
