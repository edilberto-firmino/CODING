01 / ESCOLHA A FERRAMENTA

Quatro formas de organizar informações

Uma coleção reúne vários valores em uma variável. A escolha depende de como você precisa consultar e modificar esses valores. Mutável significa que o objeto pode ser alterado depois de criado.

Comparação das coleções nativas do Python
EstruturaCriaçãoOrdem e acessoAlterável?Repetição
list[1, 2]Sequência; índiceSimPermite valores repetidos
tuple(1, 2)Sequência; índiceNão, nas posições da tuplaPermite valores repetidos
dict{"nome": "Ana"}Ordem de inserção; chaveSimChaves únicas; valores podem repetir
set{1, 2}Sem ordem garantida; sem índiceSimElementos únicos
Ordenado não significa classificado. Uma lista preserva a sequência dos elementos, mas não coloca tudo em ordem alfabética automaticamente. Dicionários preservam a ordem de inserção no Python 3.7 ou superior.

len(colecao) informa a quantidade de elementos; valor in colecao verifica pertinência. Em dicionários, in procura nas chaves.

02 / LIST

Listas: uma sequência que pode mudar

Use uma lista quando precisar manter vários itens em sequência e atualizar seu conteúdo: notas, tarefas ou nomes de estudantes. Os índices começam em 0; o índice -1 acessa o último item.

nomes = ["Ana", "Bruno", "Carla"]
print(nomes[0])
nomes.append("Diego")       # Adiciona ao final
nomes[1] = "Beatriz"       # Substitui uma posição
nomes.remove("Carla")      # Remove pelo valor
print(nomes)
print(nomes[-1])
print(len(nomes))
print(nomes[0:2])          # Do índice 0 até antes do 2

Saída esperada

Ana
['Ana', 'Beatriz', 'Diego']
Diego
3
['Ana', 'Beatriz']

insert(indice, valor) insere em uma posição; pop() remove e devolve o último item; sort() reorganiza a própria lista. Para percorrer os valores:

for nome in ["Ana", "Bruno"]:
    print(f"Olá, {nome}!")
Erros comuns: acessar uma posição inexistente gera IndexError; remover com remove() um valor ausente gera ValueError. Métodos como append() e sort() retornam None: não faça nomes = nomes.append("Eva").

Pratique · boletim de notas

Crie a lista [7.0, 8.5, 6.0], adicione 9.0, substitua a terceira nota por 7.0 e calcule a média usando sum() e len().

Conferir solução
notas = [7.0, 8.5, 6.0]
notas.append(9.0)
notas[2] = 7.0
media = sum(notas) / len(notas)
print(f"Média: {media:.2f}")  # Média: 7.88
03 / TUPLE

Tuplas: posições que permanecem fixas

Uma tupla é uma sequência imutável: não permite substituir, adicionar ou remover suas posições. É útil para representar pares e registros fixos, como coordenadas ou a identificação de uma disciplina.

disciplina = ("Python", 40)
nome, carga_horaria = disciplina  # Desempacotamento
print(nome)
print(carga_horaria)
print(disciplina[0])
unico = ("Python",)              # A vírgula cria a tupla de um item
print(type(unico).__name__)

Saída esperada

Python
40
Python
tuple

Para criar coleções vazias: lista [] e tupla (). A expressão ("Python") é apenas uma string entre parênteses.

Imutabilidade tem um limite: uma tupla não permite trocar suas posições, mas um objeto mutável dentro dela, como uma lista, ainda pode mudar. A atribuição disciplina[0] = "Java" gera TypeError.

Pratique · coordenadas

Crie uma tupla com latitude -3.73 e longitude -38.52. Desempacote os valores em duas variáveis e imprima cada uma.

Conferir solução
coordenadas = (-3.73, -38.52)
latitude, longitude = coordenadas
print(latitude)   # -3.73
print(longitude)  # -38.52
04 / DICT

Dicionários: cada valor tem uma chave

Um dicionário associa chaves a valores. Use-o para representar informações com significado, como nome, matrícula e curso de um estudante. O acesso é pela chave, e não pela posição.

aluno = {"nome": "Ana", "idade": 20, "curso": "Python"}
print(aluno["nome"])
aluno["idade"] = 21                   # Atualiza
aluno["matricula"] = "2026001"         # Adiciona
print(aluno.get("email", "Não informado"))
del aluno["curso"]                    # Remove
for chave, valor in aluno.items():
    print(f"{chave}: {valor}")

Saída esperada

Ana
Não informado
nome: Ana
idade: 21
matricula: 2026001

keys() fornece as chaves; values(), os valores; items(), os pares. {} cria um dicionário vazio. Atribuir novamente à mesma chave substitui o valor anterior.

Atenção às chaves: aluno["email"] gera KeyError se a chave não existir. Use get() para uma consulta com valor padrão. Chaves precisam ser hashable (compatíveis com hash), como strings e números; listas e dicionários não podem ser chaves.

Pratique · ficha de produto

Cadastre um produto com nome “Caderno”, preço 15.0 e estoque 10. Simule a venda de duas unidades e mostre o valor total do estoque restante.

Conferir solução
produto = {"nome": "Caderno", "preco": 15.0, "estoque": 10}
produto["estoque"] -= 2
total = produto["preco"] * produto["estoque"]
print(f"Estoque: {produto['estoque']}")  # Estoque: 8
print(f"Valor: R$ {total:.2f}")          # Valor: R$ 120.00
05 / SET

Conjuntos: cada elemento aparece uma vez

Use conjuntos para eliminar repetições, verificar presença e comparar grupos. Eles não garantem ordem de iteração e não aceitam acesso por índice.

inscritos = {"Ana", "Bruno", "Ana"}
inscritos.add("Carla")
inscritos.discard("Bruno")  # Não falha se o valor estiver ausente
print(len(inscritos))
print("Ana" in inscritos)
print(sorted(inscritos))   # Retorna uma LISTA ordenada para exibição

Saída esperada

2
True
['Ana', 'Carla']

Compare dois grupos

python = {"Ana", "Bruno"}
web = {"Bruno", "Carla"}
print(sorted(python | web))  # União: em pelo menos um grupo
print(sorted(python & web))  # Interseção: nos dois grupos
print(sorted(python - web))  # Diferença: só em Python

Saída esperada

['Ana', 'Bruno', 'Carla']
['Bruno']
['Ana']
Conjunto vazio é set(), não {}. Os elementos precisam ser hashable: strings e números funcionam, listas e dicionários não. remove() gera KeyError ao remover um item ausente; discard() não. Converter uma lista em conjunto elimina repetições, mas perde a ordem original.

Pratique · presença sem duplicidade

Transforme ["Ana", "Bruno", "Ana", "Carla", "Bruno"] em um conjunto e mostre quantas pessoas diferentes compareceram.

Conferir solução
registros = ["Ana", "Bruno", "Ana", "Carla", "Bruno"]
presentes = set(registros)
print(len(presentes))  # 3
06 / MÃO NA MASSA

Desafio: organize uma turma

Agora combine as quatro estruturas em um único programa. Trabalhe com dados fictícios e utilize os exemplos anteriores como consulta.

  1. Crie a tupla ("Fundamentos de Python", "2026.2").
  2. Crie uma lista com dois dicionários: Ana com notas [8.0, 9.0] e Bruno com notas [6.0, 7.0].
  3. Adicione Carla à lista, com notas [9.0, 10.0].
  4. Percorra a turma e mostre o nome, a média e a situação de cada estudante. A média mínima para aprovação neste exercício é 7.0.
  5. Crie um conjunto a partir dos interesses ["Python", "Web", "Python", "Dados"] e exiba seus itens em ordem alfabética.
  6. Mostre o total de estudantes e de interesses únicos.

Critérios de entrega

Salve como turma.py. O programa deve executar sem erros, usar os quatro tipos e produzir o resultado abaixo. Inclua um comentário explicando por que escolheu cada estrutura.

Fundamentos de Python | 2026.2
Ana: 8.50 - Aprovado
Bruno: 6.50 - Em recuperação
Carla: 9.50 - Aprovado
Interesses: ['Dados', 'Python', 'Web']
Estudantes: 3
Interesses únicos: 3
Abrir gabarito comentado do desafio
# Tupla: os campos de identificação ficam fixos.
disciplina = ("Fundamentos de Python", "2026.2")

# Lista: a turma pode receber novos estudantes.
# Dicionário: cada campo do estudante tem uma chave descritiva.
turma = [
    {"nome": "Ana", "notas": [8.0, 9.0]},
    {"nome": "Bruno", "notas": [6.0, 7.0]},
]
turma.append({"nome": "Carla", "notas": [9.0, 10.0]})

print(f"{disciplina[0]} | {disciplina[1]}")
for aluno in turma:
    media = sum(aluno["notas"]) / len(aluno["notas"])
    situacao = "Aprovado" if media >= 7.0 else "Em recuperação"
    print(f"{aluno['nome']}: {media:.2f} - {situacao}")

# Conjunto: cada interesse deve ser contado uma única vez.
interesses = set(["Python", "Web", "Python", "Dados"])
print(f"Interesses: {sorted(interesses)}")
print(f"Estudantes: {len(turma)}")
print(f"Interesses únicos: {len(interesses)}")

As listas de notas deste exemplo sempre têm dois valores. Como extensão, trate o caso de um estudante sem notas antes de dividir por len().

Vá além

Adicione um quarto estudante, reúna os nomes dos aprovados em uma lista e compare dois conjuntos de interesses. Explique por que um conjunto não serviria para armazenar diretamente os dicionários dos estudantes.

07 / CONSOLIDAÇÃO

Confira o que você aprendeu

1. Qual estrutura usar para uma fila de tarefas que muda?

Uma lista atende a este exercício introdutório: preserva a sequência e permite adicionar e remover tarefas. Para filas com muitas remoções no início, conheça futuramente collections.deque.

2. Uma tupla pode ter valores repetidos?

Sim. Imutabilidade diz respeito a alterações nas posições da tupla, não à exclusividade dos valores.

3. O que acontece ao atribuir outro valor à mesma chave?

O valor anterior é substituído. Um dicionário não mantém duas entradas com a mesma chave.

4. Por que não acessar um conjunto com [0]?

Conjuntos não possuem índices nem garantem ordem de iteração. Use pertinência com in ou percorra com for.

Checklist de aprendizagem

  • Consigo explicar a diferença entre mutável e imutável.
  • Sei acessar sequências por índice e dicionários por chave.
  • Sei que {} é um dicionário e set() é um conjunto vazio.
  • Consigo remover repetições e calcular uma interseção.
  • Consigo justificar a estrutura escolhida para cada informação.
