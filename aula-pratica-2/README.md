# Aula prática 2 — Retornos e módulos em Python

Abra [index.html](index.html) para acompanhar o roteiro destinado aos alunos.

Pré-requisitos: funções com parâmetros, condicionais, laços e coleções. Duração sugerida: quatro horas. Use Python 3 e um editor com terminal, sem instalar pacotes.

O aluno cria sua própria pasta de trabalho e percorre oito etapas: preparação, retorno, controle de fluxo, integração, coleções, imports, módulos e desafio com conferência. A página inclui saídas esperadas, gabarito recolhido e orientações de entrega.

O navegador exibe o material; os exemplos são executados localmente em Python. A atividade pode ser acessada pelo [menu principal](../index.html).
