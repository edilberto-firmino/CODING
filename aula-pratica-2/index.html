01 / Resultado

Mostrar um valor e devolver um valor

print() escreve na tela. return devolve um valor para o ponto que chamou a função. Esse valor pode ser guardado, comparado ou passado para outra função.

def mostrar_media(notas):
    print(sum(notas) / len(notas))


def calcular_media(notas):
    return sum(notas) / len(notas)


resultado_a = mostrar_media([8.0, 6.0])
resultado_b = calcular_media([8.0, 6.0])
print("A:", resultado_a)
print("B:", resultado_b)
print("B com bônus:", resultado_b + 1)

Saída esperada

7.0
A: None
B: 7.0
B com bônus: 8.0

Quando uma função termina sem executar um return com valor, o resultado é None, que representa ausência de valor. O número exibido por mostrar_media() não se torna seu retorno.

Sua vez · total de uma compra

  1. Crie calcular_total(preco, quantidade), que devolve a multiplicação.
  2. Guarde o retorno em uma variável e imprima o total com duas casas decimais.
  3. Use preço 15.0 e quantidade 3: o total deve ser 45.00.
  4. Em respostas.md, explique por que imprimir dentro da função não substitui devolver o valor.

02 / Fluxo

O retorno encerra a chamada atual

def definir_situacao(media):
    if media >= 7:
        return "Aprovado"
    if media >= 4:
        return "Recuperação"
    return "Reprovado"


print(definir_situacao(8.0))
print(definir_situacao(5.5))
print(definir_situacao(3.0))
Aprovado
Recuperação
Reprovado

Ao executar um return, a função termina imediatamente. No exemplo, uma média 8 não chega à segunda condição. Uma instrução colocada depois de um retorno incondicional no mesmo bloco não será executada.

Devolvendo mais de uma informação

def obter_extremos(valores):
    return min(valores), max(valores)


menor, maior = obter_extremos([6.0, 9.0, 7.0])
print(menor, maior)  # 6.0 9.0

A expressão separada por vírgula forma uma tupla. O desempacotamento distribui seus dois valores entre as variáveis. Neste exemplo, a lista precisa conter pelo menos um número.

Sua vez · todos os caminhos

  1. Execute definir_situacao() com 3.9, 4.0, 6.9 e 7.0.
  2. Crie dividir(a, b): se b for zero, devolva None; caso contrário, devolva a divisão.
  3. Ao utilizar o retorno, verifique resultado is None antes de calcular com ele.
  4. Teste dividir(10, 2), dividir(10, 0) e dividir(0, 2). Explique por que zero e None têm significados diferentes.

03 / Integração e escopo

Separe cálculo, classificação e apresentação

Reutilize calcular_media() e definir_situacao(). Uma função pode consumir o resultado da outra; a apresentação fica com quem chama.

notas = [8.0, 6.0]
media = calcular_media(notas)
situacao = definir_situacao(media)
print(f"Média: {media:.2f} | {situacao}")
Média: 7.00 | Aprovado

Parâmetros e variáveis criadas dentro de uma função têm escopo local: seus nomes pertencem àquela chamada. Devolver o valor permite utilizá-lo fora, sem depender de variáveis globais.

def aplicar_bonus(media, bonus=0.5):
    nova_media = min(media + bonus, 10.0)
    return nova_media


media_original = 7.0
media_final = aplicar_bonus(media_original)
print(media_original, media_final)  # 7.0 7.5
# print(nova_media)  # NameError: o nome é local à função.

04 / Coleções

Retorne registros e seleções de dados

alunos = [
    {"matricula": "001", "nome": "Ana", "notas": [8.0, 9.0]},
    {"matricula": "002", "nome": "Bruno", "notas": [6.0, 7.0]},
    {"matricula": "003", "nome": "Carla", "notas": [9.0, 10.0]},
]


def buscar_aluno(alunos, matricula):
    for aluno in alunos:
        if aluno["matricula"] == matricula:
            return aluno
    return None


def filtrar_aprovados(alunos):
    aprovados = []
    for aluno in alunos:
        if calcular_media(aluno["notas"]) >= 7:
            aprovados.append(aluno)
    return aprovados


encontrado = buscar_aluno(alunos, "002")
if encontrado is not None:
    print(encontrado["nome"])  # Bruno

for aluno in filtrar_aprovados(alunos):
    print(aluno["nome"])      # Ana e Carla, uma por linha
Atenção às alterações: a busca devolve o próprio dicionário guardado na lista. Alterá-lo também muda o registro original. O filtro cria uma nova lista, mas seus elementos continuam sendo os mesmos dicionários. Criar uma nova lista não copia automaticamente todos os objetos internos.

Sua vez · resumo da turma

  1. Crie resumir_turma(alunos) e devolva um dicionário com as chaves total e media_geral.
  2. Calcule a média de cada aluno e depois a média dessas médias.
  3. Para turma vazia, devolva {"total": 0, "media_geral": None}.
  4. Teste com os três alunos acima: total 3 e média geral exibida como 8.17.
  5. Busque uma matrícula inexistente e apresente “Aluno não encontrado” fora da função.

Contrato desta prática: cada aluno possui matrícula, nome e pelo menos uma nota numérica entre 0 e 10. Turma vazia é permitida. A validação de notas digitadas e o tratamento de exceções ficam para uma prática posterior.

05 / Biblioteca padrão

Use funções que já estão em outros módulos

Um módulo organiza código reutilizável. Python inclui uma biblioteca padrão que pode ser importada sem instalar pacotes.

import math

print(math.sqrt(81))  # 9.0

from math import ceil

print(ceil(7.2))      # 8

import random as sorteio

print(sorteio.choice(["Ana", "Bruno", "Carla"]))

import math permite usar o prefixo math.; from math import ceil traz o nome escolhido; as define um apelido. No sorteio, o nome exibido pode variar a cada execução.

Evite from modulo import *: os nomes importados ficam menos claros. Não chame seus arquivos de math.py ou random.py, pois isso pode interferir na importação dos módulos da biblioteca padrão.

Sua vez · dois imports

  1. Use math.ceil() para calcular quantos grupos são necessários para acomodar 23 alunos, com até 5 alunos por grupo. Resultado: 5.
  2. Use random.choice() para sortear uma matrícula entre "001", "002" e "003".
  3. Passe a matrícula sorteada para buscar_aluno() e mostre o nome retornado.
  4. Explique por que o resultado do sorteio não deve ser conferido comparando sempre com um único nome.

06 / Seus arquivos

Transforme suas funções em módulos

Na mesma pasta de experimentos.py, crie estes três arquivos. Use exatamente estes nomes para os imports abaixo funcionarem.

pratica_retornos/
├── experimentos.py
├── calculos.py
├── turma.py
├── main.py
└── respostas.md
  1. Em calculos.py, coloque calcular_media(notas) e definir_situacao(media). Deixe apenas as definições, sem chamadas de demonstração.
  2. Em turma.py, coloque buscar_aluno(), filtrar_aprovados() e resumir_turma(). No início do arquivo, use from calculos import calcular_media.
  3. Em main.py, crie os dados da turma e apresente os resultados, seguindo o exemplo abaixo.
from calculos import calcular_media, definir_situacao
from turma import buscar_aluno, filtrar_aprovados, resumir_turma


def main():
    alunos = [
        {"matricula": "001", "nome": "Ana", "notas": [8.0, 9.0]},
        {"matricula": "002", "nome": "Bruno", "notas": [6.0, 7.0]},
        {"matricula": "003", "nome": "Carla", "notas": [9.0, 10.0]},
    ]
    for aluno in alunos:
        media = calcular_media(aluno["notas"])
        situacao = definir_situacao(media)
        print(f"{aluno['nome']}: {media:.2f} - {situacao}")


if __name__ == "__main__":
    main()

Por que usar essa condição?

Ao executar python main.py, o nome especial __name__ vale "__main__", e main() é chamada. Ao importar o arquivo, essa condição é falsa. As instruções no nível principal de um módulo são executadas na primeira importação; essa proteção impede a chamada automática da demonstração.

Verifique seus módulos

  1. No terminal da pasta, execute python main.py. Você deve ver as três linhas com nome, média e situação.
  2. Execute python -c "import calculos; import turma; import main". O comando deve terminar sem imprimir a turma.
  3. Se aparecer ModuleNotFoundError, confira os nomes, a extensão .py, a localização dos arquivos e a pasta aberta no terminal.

Mantenha a direção das dependências: main importa turma e calculos; turma importa calculos. Esses módulos não precisam importar main.

Consultar gabarito de referência · abra depois de tentar

calculos.py

def calcular_media(notas):
    """Recebe notas não vazias e devolve a média aritmética."""
    return sum(notas) / len(notas)


def definir_situacao(media):
    """Recebe uma média e devolve a situação acadêmica."""
    if media >= 7:
        return "Aprovado"
    if media >= 4:
        return "Recuperação"
    return "Reprovado"

turma.py

from calculos import calcular_media


def buscar_aluno(alunos, matricula):
    """Recebe turma e matrícula; devolve o registro ou None."""
    for aluno in alunos:
        if aluno["matricula"] == matricula:
            return aluno
    return None


def filtrar_aprovados(alunos):
    """Recebe a turma e devolve uma nova lista de aprovados."""
    aprovados = []
    for aluno in alunos:
        if calcular_media(aluno["notas"]) >= 7:
            aprovados.append(aluno)
    return aprovados


def resumir_turma(alunos):
    """Devolve total e média geral; para turma vazia, a média é None."""
    if not alunos:
        return {"total": 0, "media_geral": None}
    medias = []
    for aluno in alunos:
        medias.append(calcular_media(aluno["notas"]))
    return {"total": len(alunos), "media_geral": calcular_media(medias)}

main.py

from calculos import calcular_media, definir_situacao
from turma import buscar_aluno, filtrar_aprovados, resumir_turma


def main():
    """Cria dados de exemplo e apresenta os resultados da turma."""
    alunos = [
        {"matricula": "001", "nome": "Ana", "notas": [8.0, 9.0]},
        {"matricula": "002", "nome": "Bruno", "notas": [6.0, 7.0]},
        {"matricula": "003", "nome": "Carla", "notas": [9.0, 10.0]},
    ]
    for aluno in alunos:
        media = calcular_media(aluno["notas"])
        situacao = definir_situacao(media)
        print(f"{aluno['nome']}: {media:.2f} - {situacao}")

    encontrado = buscar_aluno(alunos, "002")
    if encontrado is not None:
        print(f"Busca 002: {encontrado['nome']}")

    nomes = []
    for aluno in filtrar_aprovados(alunos):
        nomes.append(aluno["nome"])
    print("Aprovados:", ", ".join(nomes))

    resumo = resumir_turma(alunos)
    print(f"Total: {resumo['total']}")
    print(f"Média geral: {resumo['media_geral']:.2f}")

    if buscar_aluno(alunos, "999") is None:
        print("Aluno não encontrado")

    vazio = resumir_turma([])
    if vazio["media_geral"] is None:
        print("Turma vazia: Sem dados")


if __name__ == "__main__":
    main()

", ".join(nomes) reúne uma lista de strings em um texto, colocando vírgula e espaço entre os nomes. O gabarito mostra a versão com três alunos; faça você a inclusão de Diego.

08 / Conferência e entrega

Comprove o funcionamento

Crie conferir.py na mesma pasta. assert verifica uma condição: se ela for falsa, Python gera AssertionError. Use-o aqui para conferir resultados durante o desenvolvimento, não como validação de entradas do usuário.

from calculos import calcular_media, definir_situacao
from turma import buscar_aluno, filtrar_aprovados, resumir_turma

assert calcular_media([8.0, 6.0]) == 7.0
assert definir_situacao(3.9) == "Reprovado"
assert definir_situacao(4.0) == "Recuperação"
assert definir_situacao(6.9) == "Recuperação"
assert definir_situacao(7.0) == "Aprovado"
assert buscar_aluno([], "999") is None
assert filtrar_aprovados([]) == []
assert resumir_turma([]) == {"total": 0, "media_geral": None}

alunos = [
    {"matricula": "001", "nome": "Ana", "notas": [8.0, 9.0]},
    {"matricula": "002", "nome": "Bruno", "notas": [6.0, 7.0]},
    {"matricula": "003", "nome": "Carla", "notas": [9.0, 10.0]},
]
assert buscar_aluno(alunos, "002")["nome"] == "Bruno"
assert buscar_aluno(alunos, "999") is None
aprovados = filtrar_aprovados(alunos)
assert len(aprovados) == 2
assert aprovados[0]["nome"] == "Ana"
assert aprovados[1]["nome"] == "Carla"
resumo = resumir_turma(alunos)
assert resumo["total"] == 3
assert abs(resumo["media_geral"] - 24.5 / 3) < 0.000001
print("Conferências concluídas.")

Execute python conferir.py. A saída deve ser Conferências concluídas. A tolerância na última comparação permite pequenas diferenças de representação dos números decimais.
